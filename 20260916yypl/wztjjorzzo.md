# 【小贴士】女性朋友们请注意：这些事情月经期千万别做！

> 更新时间：2026-09-16 (UTC+8)

大姨妈，名词

可以代人，指代亲戚关系。

可以代物，指代女性的生理周期。

当大姨妈指代人的时候，是亲切的，温暖有爱的。

当大姨妈指代物的时候，是痛苦的，讨厌压抑的。
 

月经期是伴随卵巢周期性排卵而出现的子宫内膜脱落及出血的一种生理现象。95%的姨妈血都来自静脉血和动脉血，大部分以静脉血为主，颜色看起来也会偏暗红一些。

健康正常的大姨妈：平均28天为一个周期，经期为2-8天，平均4-6天，姨妈血量为5-80ml。

**经期有什么特殊的?**

月经除了激素变化导致子宫内膜脱落、出血的现象外，由于激素变化，女性身体还会发生一些其他变化。

1. 外阴、阴道充血

月经期间，阴道、外阴都是充血的状态，所以有些女性月经期间性冲动会更加频繁。

2. 凝血功能变差

凝血功能指人体自身的止血能力。经期，女性的凝血功能比平时要差，但正常生活一般不会受到影响，女性自身也不太会感到明显异常。

3. 免疫力下降

受内分泌的影响，经期女性的免疫力会下降，所以这个时候感染的风险比平时更高。

4. 心理、情绪问题

经期，一部分女性会出现情绪问题。如果加上一些妇科疾病，或有痛经、出血量过多的情况，情绪问题可能会更严重。

**经期哪些事不推荐?**

**1. 体检、手术及各种侵入性的医学操作**

经期受荷尔蒙分泌的影响，体检难以得到真实数据。

经期凝血功能会变差，有研究表明，月经期间进行手术会增加出血量，身体免疫力也会下降，感染的风险比平时高。同样的道理，经期也不能进行拔牙、胃镜、肠镜等各种侵入性的、会导致出血的医学操作。

特别提醒：

打耳洞也不建议在经期进行。

**2. 献血**

理由跟上面一样，经期凝血功能较差，献血后止血是比较大的问题。

月经本身就是出血了，血容量会减少，再献血，瘦弱的女生很容易出现晕厥等低血容量性危险。

**3. 不宜盆浴**

经期宫颈分泌的黏液栓稀薄，宫颈口基本处于通畅的状态，这时候盆浴时，阴道和水中的细菌有可能进入子宫。而这时的子宫，充满了刚刚脱落的新鲜内膜，还有丰富的血液和新鲜的创面，简直就是细菌滋生的天堂，非常容易引起子宫内膜炎等盆腔炎症。

同样的理由，也不建议月经期游泳。

**注意：**只是禁止盆浴，并不是不能洗澡洗头，最好采用淋浴。月经期处于更容易感染的状态，所以个人清洁更重要。就算做不到每天淋浴，经期至少也要每天睡前用清洁的温水擦洗外阴。但不要使用任何洗液，更不要冲洗阴道。

****

**4. 不宜剧烈运动**

对于痛经、月经量过大的女性，不建议经期运动。尤其是纵向及骑跨类运动，比如跳高、跨栏、打篮球、骑自行车等。长时间骑自行车，还容易损伤充血的子宫及外阴，需要格外小心。

经期运动倒不是会导致什么严重的后果，更不会跟什么癌症挂钩，只是经期剧烈运动、性生活等，不仅容易使痛经加剧、出血更多、增加盆腔感染的几率，还可能使子宫内膜进入输卵管或血管，种植到盆腔或身体的其他地方，引起各种症状的子宫内膜异位症。

**5. 不宜捶腰**

腰酸腿胀时，我们通过捶打酸胀的肌肉来缓解不适，同样，不少女性在经期也会习惯性地捶打腰部缓解腰部酸胀。

但这么做却犯了错。专家指出，此时捶打腰部会导致盆腔更加充血，反而加剧酸胀感。另外，经期捶腰还不利于子宫内膜剥落后创面的修复愈合，导致流血增多，经期延长。

**6. 不宜与人争吵**

吵嘴会妨碍脑埀体和卯巢的分泌功能；

引起神经和内分泌功能的紊乱；

导致痛经、闭经、经期延长经血过多等月经不调疾病的发生。

**7、不适宜吃生冷的蔬菜水果和冰冷的饮料**

过份生冷的食物，会降低血液循环的速度，进而影响子宫的收缩，及经血的排出，致经血排出不利，引起月经痛。

**8、不适宜喝浓茶、咖啡**

这类饮料中咖啡因含量很高，容易刺激神经和心血管，以致产生月经疼痛、经期延长和经血过多等不适症状。

**9、不适宜吃太咸**

过咸的食物，会使体内的盐分和水分贮留增多，在月经来前，很容易发生头痛、情绪激动和容易生气等症状。

**10、不宜饮酒**

同样是受体内荷尔蒙分泌影响，经期女性体内的解酒酶减少，因此饮酒易醉。更严重的是，为了制造出分解酶来帮助分解酒精，肝脏负担明显加重，因此在这期间饮酒会对肝脏造成比平日严重的伤害，引发肝脏机能障碍的可能性增大。
